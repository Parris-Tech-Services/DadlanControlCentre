## Power fault and work performed

- **Initial symptom:** Would not power on; white charging indicator beside DC jack flashed repeatedly when adapter was connected.
- **Fault identified by user:** Bent pin in the charging connector.
- **Outcome:** After the user addressed the bent pin, the laptop powered on, displayed the HP logo and reached the Windows Administrator sign-in screen.
- **Account recovery:** User used **USB #8 (Lexar 16 GB, Ventoy)** to boot **Hiren's BootCD PE** and reported resetting the local Administrator password and obtaining administrator access. No password or account secret is included here.
- **Boot media confirmed:** USB #8 launches Ventoy and the Hiren's PE desktop successfully on this laptop.
- **Installed Windows evidence update:** The separately supplied 9 Oct 2026 System Information report names **Windows 10 IoT Enterprise LTSC build 19044**, C:\\Windows, DESKTOP-J9R7MTJ and the internal Intel SSD. This is strong evidence of the installed Windows environment (rather than relying on the earlier Hiren's recovery desktop screenshot). Windows activation reports `LicenseStatus=1` (activated); lawful/transferable licensing entitlement is not established by this output.

## PowerShell diagnostics update — 9 October 2026

Source: user-submitted PowerShell console output from the HP ProBook 450 G5. This is a **single observation during active BitLocker decryption**, not a long-term stress or idle-temperature measurement.

- `Get-PhysicalDisk`: **Intel SSDPEKKF256G7H — Healthy, OK**.
- `Get-StorageReliabilityCounter`: `Temperature = 66°C`, `TemperatureMax = 75°C`, `Wear = 0`. Values for power-on hours and corrected/uncorrected read/write errors were blank / not supplied; do not interpret blanks as zero.
- `Get-CimInstance Win32_PhysicalMemoryArray`: reports **2 memory slots**, maximum capacity value 33,554,432 KB (32 GiB); actual 1×8 vs 2×4 layout still unverified.
- `Get-NetAdapter`: Intel Wireless-AC 8265 **Up, 585 Mbps reported link speed**; Realtek GbE disconnected, not tested as faulty.
- `Get-CimInstance SoftwareLicensingProduct`: `Windows(R), IoTEnterpriseS edition`, **`LicenseStatus = 1`**. This is Windows activation status, not proof of licensing entitlement.
- `manage-bde -status C:`: **Decryption in Progress**: successive readings 14.0%, 12.8%, 10.5%, 8.7%, 6.4%, 5.5% encrypted. **Protection Off**, **Unlocked**, XTS-AES 128, TPM and numerical recovery key protectors configured. This is a **historical progression, not a claim that decryption is still underway now**. Do not post recovery key values to GitHub.
- `Get-PnpDevice | Where-Object Status -ne 'OK'`: returned a broad unfiltered list that includes stale/non-present devices (e.g. ThinkPad-related items on an HP). Do **not** label every listed entry a current fault. The independent System Information export separately identified missing `ACPI\\HPQ6007` driver; verify present-only device status in a focused check.
- Both charging stability after the pin repair and sustained SSD temperature under normal load remain to be verified.
